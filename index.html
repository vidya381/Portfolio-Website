Weather Insights

       

Weather Insights is an AI-powered weather analytics platform that combines real-time weather data with machine learning to provide intelligent insights beyond basic forecasts. Built with React and FastAPI, it features anomaly detection using Z-Score analysis, temperature trend predictions with linear regression, and pattern clustering with K-Means. Users can track multiple cities with automated hourly data collection, detect unusual weather patterns, and receive 7-day predictions with confidence intervals. The platform showcases full-stack development with ML integration, featuring user authentication, favorite cities management, and comprehensive weather analytics with interactive Recharts visualizations.

MySpendo

         

MySpendo is a full-stack personal finance management platform built with Next.js 15 and Go. Track income, expenses, and budgets with automated recurring transactions for subscriptions and bills. Features advanced filtering with 12 operators, customizable budget alerts with thresholds, and comprehensive financial analytics with interactive Recharts visualizations. Backend powered by Go with JWT authentication, bcrypt password hashing, and rate limiting (5 req/min auth, 100 req/min API). Includes background jobs for automatic recurring transaction processing using PostgreSQL advisory locks, handling edge cases like month-end dates and leap years. Export transactions to CSV/JSON and visualize spending patterns across categories and time periods.

Data Playground

     

A browser-based data transformation tool built with Next.js 16 and TypeScript that handles JSON/CSV parsing, filtering, and format conversion entirely in the browser. Features smart JSON parsing that handles nested objects, API responses, and single objects, not just clean arrays. Includes 12 advanced filter operators with type inference that scans data to detect column types (string, number, boolean, date, etc.). Session sharing powered by Neon serverless PostgreSQL with 8-character short URLs that auto-expire after 7 days. Built with TypeScript strict mode, pre-commit hooks for code quality, and feature branch workflow with 38 commits across 7 milestones. All data processing happens client-side for privacy unless explicitly saved.
